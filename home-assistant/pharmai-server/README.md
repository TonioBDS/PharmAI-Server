# PharmAI Server — app Home Assistant

Serveur de partage pour l'application PharmAI (armoire à pharmacie de la maison) : il relaie
entre les téléphones du foyer les modifications **chiffrées de bout en bout**, sans pouvoir les lire.

Sharing server for the PharmAI medicine cabinet app: it relays end-to-end encrypted changes
between the household's phones, without being able to read them.
