# Journal des versions

## 0.6.0

- Recherche d'images pour la photo des produits : avec une clé Brave Search (option `brave_search_key`), l'app affiche une grille d'images à toucher, sans passer par le navigateur.

## 0.5.2

- Photos supprimées dans l'app : leur copie chiffrée est aussi effacée du serveur (par un administrateur, une semaine après).
- Un téléphone restreint ne peut pas effacer les photos d'une personne qui ne lui est pas partagée.

## 0.5.1

- Première version de l'app Home Assistant.
- Le serveur lit les options saisies dans Home Assistant.

## 0.5.0

- Kit de secours, personnes du foyer partagées par téléphone, effacement des partages inactifs.
